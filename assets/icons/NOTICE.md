# Agent icons

The notifier shows these as the notification icon. They are copied from
[herdr-focus-notify](https://github.com/yankewei/herdr-focus-notify)
(`assets/icons/agents`), which vendors them as follows.

Every icon except `omp.png` and `pi.png` is extracted from
`@lobehub/icons-static-png@1.91.0`.

- Package: https://www.npmjs.com/package/@lobehub/icons-static-png

`omp.png` is the official `favicon.svg` of the Oh My Pi coding agent
(https://omp.sh, https://github.com/can1357/oh-my-pi). License: MIT.

`pi.png` is the official `pi-logo-on-light.svg` of the Pi coding agent
(https://pi.dev, https://github.com/earendil-works/pi). License: MIT.
